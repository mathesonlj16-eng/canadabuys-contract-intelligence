## Actual Québec file inspection

The [November 2–8 weekly JSON](https://www.donneesquebec.ca/recherche/dataset/d23b2e02-085d-43e5-9e6e-e1d558ebfdd5/resource/5d0672c8-8ac3-435d-8574-9c1fad141722/download/hebdo_20261102_20261108.json) published November 9 downloaded successfully. It was 18,308,654 bytes, with 4,618 French releases, including 317 initial active tender releases with dates and notice links. It also contained 2,963 releases tagged tenderUpdate and 68 tagged tenderCancellation. Of the updates, 1,407 omitted a closing timestamp. The file uses OCDS-inspired release packages with a source OCID, release ID, release timestamp, tender ID, date fields with offsets, tags and a buyer notice link in the tender documents. [Official JSON specification](https://www.donneesquebec.ca/recherche/dataset/systeme-electronique-dappel-doffres-seao/resource/271331f3-bbdb-42f7-a052-0c75b524287d)

For the first import, use only official resources, retain OCID and release identity, and order releases by their source timestamp. Test amendment handling across overlapping files and avoid clearing known deadlines on sparse updates. Treat a weekly file as a set of releases, with no cancellation inferred from absence. Keep award events distinct and flag a potential cross-source match only when buyer and solicitation evidence support it. Preserve source identifiers independently. Apply attribution to stored and displayed data, and link the publisher's notice.

The feasibility check used the existing local stack and free downloads. No SEAO records have been added to the live directory. The next implementation step is a bounded import into a disposable database to verify history, replay and source health before enabling a local refresh.
