# Procurement sources and coverage

## CanadaBuys validation on November 10, 2026

Public Services and Procurement Canada publishes the Open and New tender files. Contains information licensed under the Open Government Licence – Canada. [Official catalogue](https://open.canada.ca/data/en/dataset/6abd20d4-7a1c-4b38-baa2-9525d0bb2fd2) · [Dataset guide](https://donnees-data.tpsgc-pwgsc.gc.ca/ba2/ac-cb/soutien-support-eng.html) · [Data dictionary](https://donnees-data.tpsgc-pwgsc.gc.ca/ba2/ac-cb/achatscanada-canadabuys-dd.xml) · [Licence](https://open.canada.ca/en/open-government-licence-canada)

| Observed field | Use and findings |
| --- | --- |
| UTF-8 with BOM, 67 CSV columns | Quoted fields can span lines. Strict parsing checks row width and required headers. Some source text already contains replacement characters despite valid UTF-8. |
| `referenceNumber-numeroReference` | Unique within the Open snapshot. The app combines it with the source name for a stable local key. |
| `solicitationNumber-numeroSollicitation` | Search and cross-dataset lookup. The 944 Open rows contained 930 distinct solicitation numbers, so the app does not merge records by solicitation alone. |
| `amendmentNumber-numeroModification` and `amendmentDate-dateModification` | Numbers are usually zero-padded, with historical alphanumeric values documented. Preserve raw values. Later numeric revisions take precedence over older rows. Source dates may be blank and are retained as supplied. |
| `publicationDate-datePublication` | Date-only, usually ISO YYYY-MM-DD. Nine Open rows had a blank publication date. These are absent from the publication-month chart. |
| `tenderClosingDate-appelOffresDateCloture` | Observed ISO timestamps without an offset. The dictionary specifies fixed UTC−05:00. The app stores UTC and displays Eastern time using the applicable DST rules. An absent or date-only value does not establish a deadline time. |
| `tenderStatus-appelOffresStatut-eng` | Both current files reported `Open` for every row, including records with elapsed deadlines. A separate 1 MiB range request to the 2026–2027 file confirmed `Expired` and `Cancelled` rows. That sample was used for inspection. |
| `title-titre-eng`, `contractingEntityName-nomEntitContractante-eng`, `tenderDescription-descriptionAppelOffres-eng` | English content with French fallback. The two languages are columns of the same row. |
| `procurementCategory-categorieApprovisionnement`, `unspscDescription-eng`, `gsinDescription-nibsDescription-eng` | Categories have asterisks and can span lines. The live file used `SRVTGD` for services related to goods. Industry summaries use the first available commodity description and can omit secondary classifications. |
| `noticeURL-URLavis-eng`, `attachment-piecesJointes-eng` and French equivalents | The buyer URL is often blank. The Open file included 424 English notice URLs and 408 English attachment fields. Attachment fields can contain multiple comma-delimited links. For CanadaBuys webform references, the UI builds a direct notice link and also offers solicitation search. |
| Budget | The tender files have no amount or currency columns. Budget analysis uses the existing curated amounts or owner-entered CAD ceilings. |

The initial Open import added 944 notices. New added 40 unique notices, updated one existing row and matched one unchanged row. The live update affected trade-agreement and limited-tendering metadata with the amendment number unchanged. An Open replay skipped that older row and matched the other 943. A New replay matched all 42 rows unchanged. The database retained 547 records with nonzero amendment numbers, and a controlled test using an edited copy of a real row preserved the original and numbered amendment, then deduplicated a replay. The application stores the official file SHA-256, source publication time, row-level hashes and both observed versions for changes. It can only preserve revisions received after collection starts.

Five official notice pages returned HTTP 200 and their displayed closing date and time matched the CSV after conversion: [Windsor phone booths](https://canadabuys.canada.ca/en/tender-opportunities/tender-notice/cb-137-57474395), [trade information subscription](https://canadabuys.canada.ca/en/tender-opportunities/tender-notice/cb-1-28025376), [mechanical systems](https://canadabuys.canada.ca/en/tender-opportunities/tender-notice/cb-14-50306973), [calcium trisodium pentetate](https://canadabuys.canada.ca/en/tender-opportunities/tender-notice/cb-141-88756202) and [electrode calendaring](https://canadabuys.canada.ca/en/tender-opportunities/tender-notice/cb-158-22140534).

The Open file is published daily and the New file is published every two hours during the stated daytime window. Lag, third-party portal availability and missing addenda can affect coverage. The 48-hour freshness threshold is a local policy. The directory has no complete historical or awards corpus. Analytics describe the records collected here and are sensitive to that coverage. Ranking uses deterministic term matching and owner review. Manual qualification, full document extraction, and a separately labelled 20-notice ranking benchmark remain open.

## Prioritized expansion

| Priority | Official source and coverage | Permitted integration path |
| --- | --- | --- |
| 1 | CanadaBuys fiscal-year tenders and separate awards include federal history. [Procurement datasets](https://canadabuys.canada.ca/en/procurement-and-contracting-data) | Official CSV downloads and keyless Open Government CKAN metadata API. Add a bounded historical backfill and separate award tables. Join candidate records by solicitation and buyer, checking duplicate identifiers and currency. Distinguish award values from tender ceilings. |
| 2 | Ontario Tenders Portal for provincial competitive opportunities. Ontario's Open Government Catalogue publishes VOR datasets. [Ontario supplier guide](https://www.ontario.ca/page/doing-business-government-ontario) · [Procurement open data guide](https://www.ontario.ca/document/open-data-guidebook-guide-open-data-directive/procurement-and-contracts) | Use official listing links for targeted manual review. Confirm an authorized live API/export and licence with Supply Ontario before automation. VOR data can support research separately from live notices. |
| 3 | Québec SEAO covers government, education, health and municipalities. [Données Québec SEAO catalogue](https://www.donneesquebec.ca/recherche/dataset/systeme-electronique-dappel-doffres-seao) | Official downloadable JSON for open notices and awards, and XML for historical awarded contracts. Catalogue lists CC BY 4.0. Validate schema, cadence, French scope text and provenance using a weekly JSON file. |
| 4 | Toronto Bids Portal for municipal open solicitations, pending awards and contract history. [Toronto Bids Portal](https://www.toronto.ca/business-economy/doing-business-with-the-city/searching-bidding-on-city-contracts/toronto-bids-portal/) | Public browser review and official links. Confirm a sanctioned export/API and terms with the city before automating. SAP Ariba access can be required for procurement documents. |
| 5 | Alberta Purchasing Connection and BC Bid cover provincial and participating broader public-sector entities. [Alberta supplier guide](https://www.alberta.ca/get-started-as-a-supplier) · [BC Bid history guide](https://www2.gov.bc.ca/assets/gov/bc-procurement-resources/bc-bid-guides/pdf-quick-reference/legacy_bc_bid_qrg.pdf) | Public browsing and source links. Review approved bulk access and reuse terms before connecting. Alberta requires registration for bid documents and some features. |
| 6 | Direct nonprofit and association procurement, including OCASI and FCM. [OCASI opportunities](https://ocasi.org/careers-ocasi) · [Example FCM buyer RFP](https://media.fcm.ca/image/upload/v1730383842/people-and-culture/FCM_E_Learning_Module_Development_RFP.pdf) | Use source-linked manual capture and verify the original buyer and deadline. No public bulk API or export was verified for these organizations. Review each publisher's terms before automating. |

Automatic collection currently covers the two CanadaBuys federal files. The other sources above are roadmap entries. The bundled `fixtures/known_research.json` holds four fictional manually entered records that show how prior research is kept separate from live feed data.
